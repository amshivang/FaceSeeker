# FaceSeeker 🕵️‍♂️🔍

> 100% Offline Target Face Detector for Law Enforcement & Forensic Surveillance Analysis (Windows Desktop App)

## 📋 Overview
FaceSeeker is a powerful, fully offline Windows desktop application designed for law enforcement and forensic analysts. It enables rapid and accurate target face detection across surveillance footage and image datasets without requiring an internet connection, ensuring data privacy and security.

## ✨ Features
- **100% Offline Processing:** Completely local execution with no data leaving the machine.
- **High-Accuracy Face Detection:** Advanced models for robust detection in challenging conditions.
- **Forensic Analysis Tools:** Built specifically for surveillance and investigative workflows.
- **Windows Desktop App:** Native, optimized performance for Windows environments.
